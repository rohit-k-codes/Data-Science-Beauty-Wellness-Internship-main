## Notes on Missing Values

- `skin_type` missing values: treated as **unknown**. Never imputed. Rows with missing skin_type are excluded from skin-type comparisons but retained for other analyses.
- `review_text` missing values: row is dropped (no review text = unusable for NLP).
- `rating` missing values: row is dropped (no target = unusable for modelling).
- All other missing values: documented in cleaning log; handled on a field-by-field basis.

## Feature Inventory (Week 3 Existing and Week 4 EDA)

| Feature Name | Source Field(s) | Type | Description |
|-------------|-----------------|------|-------------|
| review_length_words | review_text_clean | Integer | Number of whitespace-separated tokens; recomputed in Week 4 EDA output |
| review_length_chars | review_text_clean | Integer | Number of characters; recomputed in Week 4 EDA output |
| review_text_clean | review_text | String | Week 3 conservative normalization: strip HTML/URLs, replace non-ASCII characters, lowercase, collapse repeated punctuation/whitespace; negation is preserved |
| skin_type_known | skin_type | Boolean | True if a non-empty canonical skin type other than `unknown` is present; descriptive metadata, not a recommendation signal |
| rating_band | rating | Categorical string | Descriptive grouping: low (1–2), middle (3), high (4–5); derived from the outcome and must not be used as a predictor of rating |

The Week 4 feature output is saved separately as `data/processed/reviews_eda_features.csv`; the Week 3 cleaned CSV is not modified. Keyword indicators, skin-type encodings, and category encodings listed in earlier drafts are not generated by this EDA pipeline. Review wording is not validated evidence of a customer's skin concern or a product's suitability.

## Week 5 Modeling

The Week 5 task predicts the observed review-level `is_recommended` flag for
rows with a valid 0/1 label, using `review_text_clean` and `skin_type`.
`rating` and rating-derived fields are excluded because rating is strongly
associated with the recommendation label; post-review feedback counts,
product identifiers, and reviewer identifiers are also excluded from model
predictors. `author_id` is used only to keep reviewers within a single holdout
partition or cross-validation fold. The full cleaned dataset contains 811,974
valid target labels (683,626 positive and 128,348 negative) and 157,911 missing
target values. Week 5 results are an exploratory prediction of the recorded
label, not evidence of efficacy, safety, skin concerns, or individual product
suitability.
